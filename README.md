# Aderência escolar / gestão

Complementos de gestão escolar que fecham lacunas do núcleo: provas/gabarito, uniforme, marca d’água, anexos e fluxos auxiliares.

Composer: `buriti/i-educar-escolar-aderencia-package`

## Para que serve

Empacota melhorias pontuais sobre o escolar do i-Educar e do i-Diário — sem forkar o core — para atender rotinas de prova, identidade visual de documentos, uniforme e anexos móveis.

## Desenho de funções

| Função | Entrega |
| --- | --- |
| Gabarito / provas | Fluxos de prova escaneada e gabarito |
| Uniforme escolar | Controle e consulta relacionados ao uniforme |
| Marca d’água / identidade | Padronização visual em artefatos escolares |
| Anexos móveis | Suporte a anexos em fluxos escolares |
| Compra de vagas / secundárias | Ajustes de gestão previstos no escopo do pacote |

## Quem usa

- Secretaria escolar
- SME
- Professores (pontos de contato no diário)

## Integrações

- Núcleo escolar
- i-Diário
- Apps API
- Exportação / relatórios

## Compatibilidade

| Produto | Versão |
| --- | --- |
| **i-Educar** | **2.12.x** |
| **i-Diário** | Portabilis i-Diário (API / SSO do núcleo) |

Declarado em `composer.json` → `extra.ieducar` / `extra.idiario`.
